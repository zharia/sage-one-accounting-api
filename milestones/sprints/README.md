# Sprints

Sprints split milestones into shippable slices (spec §22).

## Rules

- IDs: `M00X-S0Y` (e.g. `M001-S01`). Stable, never reused.
- A sprint belongs to exactly one milestone and cannot outlive its acceptance.
- Every sprint has: objective, included tasks, task dependencies, Definition of Done, verification requirements, completion report.
- Do not overwrite completed sprint specs — append amendments.
- Sprint acceptance feeds the parent milestone's acceptance criteria.
